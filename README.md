# Laya Pro

Benvenuti in **Laya Pro**, una piattaforma AI ibrida avanzata. Laya Pro coordina motori decisionali strutturati, modelli linguistici di grandi dimensioni e sistemi di orchestrazione.

Laya Pro integra:
- **System 1 (Laya local core / JEV)**: elaborazione rapida, strutturata e basata su regole.
- **System 2 (Nemotron)**: ragionamento complesso, generazione di linguaggio naturale e analisi profonda.
