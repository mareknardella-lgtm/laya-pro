# Riferimento API

Le API di Laya Pro permettono l'interazione programmatica con la piattaforma. Questa sezione sarà espansa man mano che l'integrazione di JEV verrà completata.

## Endpoint Principali
- \/chat\: Invia un messaggio all'assistente (supporta le modalità LOW, MEDIUM, HARD).
- \/memory/query\: Cerca informazioni all'interno del sistema RAG SQLite.
- \/status\: Restituisce lo stato operativo dei backend (System 1 e System 2).
