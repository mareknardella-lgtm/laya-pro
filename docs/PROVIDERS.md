# Provider Supportati

Laya Pro è progettato per interfacciarsi con molteplici provider AI.

## Modelli Principali
- **Nemotron**: Il motore LLM principale (System 2) per ragionamenti complessi.
- **JEV (Laya Local Core)**: Motore di esecuzione basato su logica strutturata (System 1).

Configura i tuoi provider attraverso le variabili d'ambiente o i file di configurazione, assicurandoti di inserire le chiavi API necessarie (se applicabile).
