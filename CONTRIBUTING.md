# Linee Guida per Contribuire

Siamo felici che tu voglia contribuire a Laya Pro!

## Come Contribuire
1. Fai un fork del repository.
2. Crea un branch per la tua funzionalità o correzione (git checkout -b feature/nuova-funzionalita).
3. Effettua i commit delle tue modifiche.
4. Fai il push del branch (git push origin feature/nuova-funzionalita).
5. Apri una Pull Request.

Per maggiori dettagli, consulta la [Documentazione di Sviluppo](docs/DEVELOPMENT.md).
